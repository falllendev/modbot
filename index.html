1. Connect

First-time setup (one time, free)
  1. Go to console.cloud.google.com → create a project.
  2. APIs & Services → Library → enable YouTube Data API v3.
  3. OAuth consent screen → External → add yourself under Test users.
  4. Credentials → Create → OAuth client ID → Web application. Add your GitHub Pages URL (e.g. https://USERNAME.github.io) under Authorized JavaScript origins.
  5. Paste the Client ID below.

Commands

Use {user} and {args} in replies. Cooldown in seconds.

Timed messages

Sends every N minutes, only if at least M chat messages came in since the last one.

Filters (mods & the owner are always exempt)

Heads up: deleting costs ~50 quota units, timeouts ~200 more. See the quota counter up top.
